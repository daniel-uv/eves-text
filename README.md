# Eve's Text

Eve's Text — простой текстовый редактор для Linux (GTK 3 + GtkSourceView 4 + gspell).
База для будущей ИИ-проверки грамматики и пунктуации на русском.

## Возможности

- Новый / открыть / сохранить / сохранить как, подтверждение несохранённых правок
- Чтение UTF-8 и CP1251 (старые русские файлы), запись всегда в UTF-8, атомарно
- Автоматическое определение светлой/тёмной темы и схемы подсветки
- Номера строк (по умолчанию выключены), подсветка текущей строки, перенос строк
- Поля вокруг текста: документ не прилипает к краям окна
- Нижняя панель: размер шрифта, выравнивание абзацев (лево/центр/право/по ширине),
  Tab вставляет символ табуляции (шаг 4 знака); кнопка включения/выключения ИИ
- Проверка орфографии через **gspell** (русский `ru_RU`): ошибки подчёркиваются,
  правый клик — варианты замены и «Добавить в словарь»
- **Проверка с ИИ**: выделите текст, правый клик → «Проверить с ИИ» —
  локальная модель через Ollama исправляет орфографию, грамматику и пунктуацию
- Строка состояния: позиция курсора, кодировка, число слов и символов
- Открытие файла из терминала, drag & drop в окно
- Сборка в `.deb` и установка в меню приложений со своей иконкой

## Запуск из исходников

```bash
./run.sh                    # пустой документ
./run.sh путь/к/файлу.txt   # сразу открыть файл
python3 -m eves_text --version
```

Требования: `python3-gi`, `gir1.2-gtk-3.0`, `gir1.2-gtksource-4`, `gir1.2-gspell-1`,
`hunspell-ru` (словарь). На Linux Mint/Ubuntu они уже стоят.

Для проверки с ИИ нужен [Ollama](https://ollama.com) и модель (см. ниже).
Без Ollama редактор работает как обычно, пункт «Проверить с ИИ» покажет подсказку.

## Сборка и установка .deb

```bash
./packaging/build-deb.sh                 # -> dist/eves-text_0.5.5-1_all.deb
sudo dpkg -i dist/eves-text_0.5.5-1_all.deb
eves-text                                # или из меню «Eve's Text»
```

Свой сопровождающий в метаданных:

```bash
MAINTAINER="Имя <mail@example.org>" ./packaging/build-deb.sh
```

Пропустить послетборочную проверку: `SKIP_TEST=1 ./packaging/build-deb.sh`.

Проверить пакет без установки:

```bash
dpkg-deb --info dist/eves-text_0.5.5-1_all.deb
dpkg-deb -c dist/eves-text_0.5.5-1_all.deb
dpkg-deb -x dist/eves-text_0.5.5-1_all.deb /tmp/eves-text-root
/tmp/eves-text-root/usr/lib/eves-text/eves-text --version
```

Удаление: `sudo dpkg -r eves-text`.

Зависимости в `control`: `python3`, `python3-gi`, `gir1.2-gtk-3.0`,
`gir1.2-gtksource-4`, `gir1.2-gspell-1`; рекомендуется `hunspell-ru`.

## Горячие клавиши

| Действие            | Клавиши              |
|---------------------|----------------------|
| Новый / Открыть     | Ctrl+N / Ctrl+O      |
| Сохранить / Как     | Ctrl+S / Ctrl+Shift+S|
| Отменить / Вернуть  | Ctrl+Z / Ctrl+Shift+Z|
| Вырезать/копировать | Ctrl+X / Ctrl+C      |
| Вставить            | Ctrl+V               |
| Табуляция           | Tab                  |
| Выделить всё        | Ctrl+A               |
| Выход               | Ctrl+Q               |

## Форматирование

Панель форматирования расположена внизу окна и выровнена по центру.

- **Размер шрифта** — кнопки − / + или число в поле (8–48). Шрифт моноширинный.
- **Выравнивание** — действует на выделенные абзацы или на абзац с курсором:
  по левому краю, по центру, по правому краю, по ширине.
- **Табуляция** — клавиша Tab; шаг табуляции 4 знака.
- **ИИ** — кнопка «Выключить ИИ» выгружает модель из памяти (освобождает ОЗУ и видеопамять),
  «Включить ИИ» снова разрешает проверку; модель загрузится при следующей проверке.

## Структура

```
eves-text/
├── run.sh                     запуск из исходников
├── eves_text/
│   ├── __main__.py            python3 -m eves_text
│   ├── application.py         Gtk.Application, CSS, аргументы, --version
│   ├── window.py              окно, меню, действия, статусбар
│   ├── spellcheck.py          проверка орфографии (gspell + текстовые теги)
│   ├── ai_check.py            проверка текста через Ollama (без GTK)
│   ├── document.py            чтение/запись файлов и статистика (без GTK)
│   └── resources/             style.css, eves-text.desktop
├── packaging/
│   ├── build-deb.sh           сборка пакета через dpkg-deb (без debhelper)
│   ├── control.in             шаблон метаданных
│   ├── postinst, postrm       обновление кэшей меню и иконок
│   ├── copyright              MIT
│   └── eves-text.svg          иконка приложения
├── tests/smoke_test.py        проверка без показа окна
├── build/                     временное дерево сборки (создаётся скриптом)
└── dist/                      готовые .deb
```

`document.py` и `ai_check.py` намеренно не зависят от GTK: их можно
вызывать из фонового потока и тестировать отдельно.

## Проверка с ИИ (Ollama)

Проверка выполняется локально: выделенный фрагмент отправляется службе Ollama
на этом же компьютере, в интернет ничего не уходит.

Установка (один раз):

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5:7b-instruct
```

Использование: выделите текст → правый клик → **«Проверить с ИИ»**.
Пункт появляется только при выделении. Пока идёт проверка, в строке состояния
видно сообщение; после проверки выделенный фрагмент заменяется исправленным.
Отменить замену — **Ctrl+Z**.

Кнопка **«Выключить ИИ»** на нижней панели сразу выгружает модель из памяти,
если она нужна другим программам. Проверка при этом отключается, пункт меню
исчезает; кнопка **«Включить ИИ»** возвращает всё обратно (модель загрузится
при следующей проверке).

Настройки (необязательно):

```bash
export RU_EDITOR_AI_MODEL=qwen2.5:7b-instruct   # другая модель Ollama
export RU_EDITOR_OLLAMA_URL=http://127.0.0.1:11434
```
