# Eve's Text

Eve's Text — простой текстовый редактор для Linux и Windows (GTK 3 + GtkSourceView 4 + gspell).
Текстовый редактор для русского языка с проверкой орфографии и проверкой с ИИ
через Ollama.

## Windows 11

Отдельная сборка для Windows лежит в папке [`windows/`](windows/README.md):
установщик и портативный ZIP со всем рантаймом (Python, GTK, словари).
Готовые файлы — в разделе
[Releases](https://github.com/daniel-uv/eves-text/releases);
сборка идёт автоматически через GitHub Actions.

## Возможности

- Новый / открыть / сохранить / сохранить как, подтверждение несохранённых правок
- Чтение UTF-8 и CP1251 (старые русские файлы), запись всегда в UTF-8, атомарно
- Автоматическое определение светлой/тёмной темы и схемы подсветки
- В Windows 11 заголовок окна и диалогов тоже становится тёмным при тёмной теме
- Номера строк и подсветка текущей строки (по умолчанию выключены), перенос строк
- Поля вокруг текста: документ не прилипает к краям окна
- Нижняя панель: размер шрифта, выравнивание абзацев (лево/центр/право/по ширине),
  Tab вставляет символ табуляции (шаг 4 знака); кнопка включения/выключения ИИ
- Проверка орфографии через **gspell** (русский `ru_RU`): ошибки подчёркиваются,
  правый клик — варианты замены и «Добавить в словарь»
- **Проверка с ИИ**: выделите текст, правый клик → «Проверить с ИИ» —
  локальная модель через Ollama исправляет орфографию, грамматику и пунктуацию;
  модель скачивается вручную: меню «ИИ» → «Скачать модель», там же выбирается
  папка для её хранения
- Строка состояния: позиция курсора, кодировка, число слов и символов
- Обновления: надпись «Версия актуальна» в правом нижнем углу — нажмите,
  чтобы проверить и скачать новую версию
- Открытие файла из терминала, drag & drop в окно
- Сборка в `.deb` и установка в меню приложений со своей иконкой

## Запуск из исходников

```bash
./run.sh                    # пустой документ
./run.sh путь/к/файлу.txt   # сразу открыть файл
python3 -m eves_text --version
```

Требования: `python3-gi`, `gir1.2-gtk-3.0`, `gir1.2-gtksource-4`, `gir1.2-gspell-1`,
`hunspell-ru` (словарь). На Linux Mint/Ubuntu они уже стоят.

Для проверки с ИИ нужен [Ollama](https://ollama.com); модель скачивается
вручную в меню «ИИ» → «Скачать модель» (см. ниже).
Без Ollama редактор работает как обычно, пункт «Проверить с ИИ» покажет подсказку.

## Сборка и установка .deb

```bash
./packaging/build-deb.sh                 # -> dist/eves-text_0.6.9-1_all.deb
sudo dpkg -i dist/eves-text_0.6.9-1_all.deb
eves-text                                # или из меню «Eve's Text»
```

Свой сопровождающий в метаданных:

```bash
MAINTAINER="Имя <mail@example.org>" ./packaging/build-deb.sh
```

Пропустить послетборочную проверку: `SKIP_TEST=1 ./packaging/build-deb.sh`.

Проверить пакет без установки:

```bash
dpkg-deb --info dist/eves-text_0.6.9-1_all.deb
dpkg-deb -c dist/eves-text_0.6.9-1_all.deb
dpkg-deb -x dist/eves-text_0.6.9-1_all.deb /tmp/eves-text-root
/tmp/eves-text-root/usr/lib/eves-text/eves-text --version
```

Удаление: `sudo dpkg -r eves-text`.

### Что кладёт пакет

Зависимости в `control`: `python3`, `python3-gi`, `gir1.2-gtk-3.0`,
`gir1.2-gtksource-4`, `gir1.2-gspell-1`; рекомендуется `hunspell-ru`.

## Горячие клавиши

| Действие            | Клавиши              |
|---------------------|----------------------|
| Новый / Открыть     | Ctrl+N / Ctrl+O      |
| Сохранить / Как     | Ctrl+S / Ctrl+Shift+S|
| Отменить / Вернуть  | Ctrl+Z / Ctrl+Shift+Z|
| Вырезать/копировать | Ctrl+X / Ctrl+C      |
| Вставить            | Ctrl+V               |
| Табуляция           | Tab                  |
| Выделить всё        | Ctrl+A               |
| Выход               | Ctrl+Q               |

## Форматирование

Панель форматирования расположена внизу окна и выровнена по центру.

- **Размер шрифта** — кнопки − / + или число в поле (8–48). Шрифт моноширинный.
- **Выравнивание** — действует на выделенные абзацы или на абзац с курсором:
  по левому краю, по центру, по правому краю, по ширине.
- **Табуляция** — клавиша Tab; шаг табуляции 4 знака.
- **ИИ** — кнопка «Выключить ИИ» выгружает модель из памяти и останавливает
  отдельную службу Ollama, запущенную приложением; «Включить ИИ» снова
  разрешает проверку.

eves-text/
├── run.sh                     запуск из исходников
├── eves_text/
│   ├── __main__.py            python3 -m eves_text
│   ├── application.py         Gtk.Application, CSS, аргументы, --version
│   ├── window.py              окно, меню, действия, статусбар
│   ├── spellcheck.py          проверка орфографии (gspell + текстовые теги)
│   ├── ai_check.py            проверка текста через Ollama (без GTK)
│   ├── ollama_server.py       отдельная служба Ollama с выбранной папкой
│   ├── settings.py            JSON-настройки модели и папки (без GTK)
│   ├── updates.py             проверка релизов GitHub и скачивание (без GTK)
│   ├── win_theme.py           тёмный заголовок окна в Windows (без GTK)
│   ├── document.py            чтение/запись файлов и статистика (без GTK)
│   └── resources/             style.css, eves-text.desktop
├── packaging/
│   ├── build-deb.sh           сборка пакета через dpkg-deb (без debhelper)
│   ├── control.in             шаблон метаданных
│   ├── postinst, postrm       обновление кэшей меню и иконок
│   ├── copyright              MIT
│   └── eves-text.svg          иконка приложения
├── tests/smoke_test.py        проверка без показа окна
├── build/                     временное дерево сборки (создаётся скриптом)
└── dist/                      готовые .deb

`document.py`, `ai_check.py` и `updates.py` намеренно не зависят от GTK:
их можно вызывать из фонового потока и тестировать отдельно.

## Проверка с ИИ (Ollama)

Проверка выполняется локально: выделенный фрагмент отправляется службе Ollama
на этом же компьютере, в интернет ничего не уходит.

Установка Ollama (один раз):

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### Ручное скачивание модели

Модель не скачивается автоматически. Откройте меню **«ИИ» → «Скачать модель»**,
выберите модель из списка (например, `qwen2.5:7b-instruct` — лучшее качество,
`qwen2.5:0.5b` — самая лёгкая) и укажите папку для моделей. Название можно и
ввести вручную, если нужной модели нет в списке.
Приложение создаст папку, запустит отдельную службу `ollama serve` на свободном
порту с `OLLAMA_MODELS=<выбранная папка>` и скачает модель туда. Системная
Ollama и её модели не меняются. Прогресс виден в диалоге, скачивание можно
отменить.

Выбранные модель и папка запоминаются:

- Linux: `~/.config/eves-text/settings.json`
- Windows: `%APPDATA%\Eve's Text\settings.json`

Пункт **«ИИ» → «Указать папку для моделей»** открывает окно выбора папки: выбранная
папка создаётся при необходимости и запоминается. Пункт
**«ИИ» → «Открыть папку с моделями»** показывает её в файловом менеджере. Если
папка не выбрана (пункт **«ИИ» → «Использовать системную Ollama»**), приложение
работает через системную службу на `http://127.0.0.1:11434`; модель тогда можно
поставить вручную:

```bash
ollama pull qwen2.5:7b-instruct
```

### Проверка текста

Выделите текст → правый клик → **«Проверить с ИИ»**.
Пункт появляется только при выделении. Пока идёт проверка, в строке состояния
видно сообщение; после проверки выделенный фрагмент заменяется исправленным.
Отменить замену — **Ctrl+Z**.

Если модели нет, приложение не предлагает скачать её автоматически, а пишет
в строке состояния, где это сделать вручную.

Кнопка **«Выключить ИИ»** на нижней панели сразу выгружает модель из памяти и
останавливает отдельную службу Ollama, запущенную приложением. Проверка при
этом отключается, пункт меню исчезает; кнопка **«Включить ИИ»** возвращает всё
обратно.

Настройки (необязательно):

```bash
export RU_EDITOR_AI_MODEL=qwen2.5:7b-instruct   # другая модель Ollama
export RU_EDITOR_OLLAMA_URL=http://127.0.0.1:11434
```

`RU_EDITOR_AI_MODEL` имеет приоритет над моделью, сохранённой в настройках.

## Обновления

В правом нижнем углу окна есть надпись **«Версия актуальна»**. Нажмите на неё:
приложение проверит релизы на GitHub и, если появилась новая версия, скачает
пакет. Надпись показывает прогресс, затем — «Устанавливаю X…».

- Linux: скачивается `.deb`, установка — `sudo dpkg -i <файл>`; надпись
  «Скачана версия X», повторное нажатие открывает папку с загрузкой.
- Windows: после скачивания установщик запускается автоматически (Windows
  попросит подтвердить права администратора), приложение закрывается и после
  установки открывается снова.

Проверка, скачивание и установка идут в фоне и не блокируют окно.
