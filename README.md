# Eve's Text

Текстовый редактор для русского языка: проверка орфографии и проверка текста
локальной моделью через Ollama.

**Платформы:** Linux (`.deb`) и Windows 11. Готовые сборки — в
[Releases](https://github.com/daniel-uv/eves-text/releases).

## Возможности

- Открытие и сохранение UTF-8/CP1251, атомарная запись, защита от потери правок
- Вкладки как в браузере: в каждой свой документ, имена «Документ 1», «Документ 2»…,
  активная вкладка сливается с листом; вкладки можно перетаскивать мышью, меняя порядок
  с плавной анимацией движения
- Проверка орфографии через gspell (`ru_RU`): подчёркивание ошибок, замена,
  добавление в словарь
- Проверка с ИИ: выделить текст → правый клик → «Проверить с ИИ»; работает
  локально через Ollama, в интернет ничего не отправляется
- Подсветка синтаксиса, номера строк, перенос строк, подсветка текущей строки
- Светлая и тёмная темы: переключатель в меню «Вид» («Тёмная тема»), выбор
  запоминается; цвет заголовка окна меняется вместе с темой, в том числе в Windows 11
- Панель форматирования: одно поле размера шрифта (при выделении меняет только
  выделенный текст), кнопки `B`/`I`/`U` (жирный, наклонный, подчёркнутый;
  `Ctrl+B`/`Ctrl+I`/`Ctrl+U`), выравнивание абзацев, табуляция; оформление
  сохраняется в RTF, обычный `.txt` остаётся чистым текстом
- Меню «Настройки»: размер шрифта и выравнивание по умолчанию, выбор запоминается
- Строка состояния: позиция курсора, кодировка, число слов и символов
- Drag & drop файла прямо в окно ввода, открытие файла из терминала,
  автоматические обновления
- Windows 11: нативный GUI-`.exe`, выбирается в «Приложениях по умолчанию»
  для `.txt` и `.rtf`, без окна командной строки; файлы из Проводника
  открываются перетаскиванием через собственный COM `IDropTarget`

## Установка

### Linux

Скачайте `.deb` из [Releases](https://github.com/daniel-uv/eves-text/releases)
и установите:

```bash
sudo dpkg -i eves-text_0.6.57-1_all.deb
eves-text
```

Удаление: `sudo dpkg -r eves-text`.

Сборка пакета:

```bash
./packaging/build-deb.sh        # -> dist/eves-text_0.6.57-1_all.deb
```

### Windows 11

В [Windows-релизе](https://github.com/daniel-uv/eves-text/releases/tag/win-v0.6.57)
есть установщик `.exe` и портативный `.zip`. Рантайм (Python, GTK, словари)
уже включён — устанавливать ничего дополнительно не нужно.

## Запуск из исходников

```bash
./run.sh                    # пустой документ
./run.sh путь/к/файлу.txt   # открыть файл
python3 -m eves_text --version
```

Требования: `python3-gi`, `gir1.2-gtk-3.0`, `gir1.2-gtksource-4`,
`gir1.2-gspell-1`, `hunspell-ru`. В Linux Mint и Ubuntu они уже установлены.

## Проверка с ИИ

Модель скачивается только вручную: меню **«ИИ» → «Скачать модель»**. Там же
выбирается модель и папка для хранения. Например:
`qwen2.5:7b-instruct` — лучшее качество, `qwen2.5:0.5b` — самая лёгкая.

Приложение запускает отдельную службу Ollama на свободном порту и не меняет
системную. Можно использовать и системную Ollama
(`http://127.0.0.1:11434`) — пункт **«ИИ» → «Использовать системную Ollama»**.

Установка Ollama (если её нет):

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Новый / открыть | Ctrl+N / Ctrl+O |
| Закрыть вкладку | Ctrl+W |
| Следующая / предыдущая вкладка | Ctrl+Tab / Ctrl+Shift+Tab |
| Сохранить / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Отменить / вернуть | Ctrl+Z / Ctrl+Shift+Z |
| Вырезать / копировать / вставить | Ctrl+X / Ctrl+C / Ctrl+V |
| Выделить всё | Ctrl+A |
| Выход | Ctrl+Q |

## Обновления

Надпись **«Версия актуальна»** в правом нижнем углу проверяет релизы на GitHub.
Новая версия скачивается и устанавливается автоматически: в Linux — через
графический запрос пароля, в Windows — через установщик. После установки
приложение перезапускается.

## Разработка

```bash
python3 tests/smoke_test.py     # проверка без показа окна
```

Структура:

```
eves_text/            код приложения (GTK, редактор, ИИ, обновления)
eves_text/resources/  стили, иконки, .desktop
packaging/            сборка .deb
windows/              сборка для Windows 11
tests/                смоук-тест
```

`document.py`, `ai_check.py` и `updates.py` не зависят от GTK и подходят для
фоновых потоков и отдельных тестов.
